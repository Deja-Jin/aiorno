# Тест «Настоящее или ИИ?»

## Запуск
1. Установи Python 3.10 или новее.
2. В терминале в папке проекта выполни: `python -m pip install -r requirements.txt`
3. Запусти: `python app.py`
4. Открой адрес, который Flask покажет в терминале (обычно http://127.0.0.1:5000).

## Добавление изображений
- Настоящие фото: `static/images/real/`
- Соответствующие версии ИИ: `static/images/ai/`

Для каждой пары используй одинаковое основное имя:
- `real/photo1.jpg` ↔ `ai/photo1_ai.jpg`
- `real/cat.png` ↔ `ai/cat_ai.png`
- `real/street.webp` ↔ `ai/street_fake.webp`

Поддерживаемые суффиксы ИИ: `_ai`, `-ai`, ` ai`, `_fake`, `-fake`, ` fake`, `_generated`, `-generated`, ` generated`.
Основная часть имени должна совпадать без учёта регистра. Расширения у двух файлов могут различаться.

В тест попадут только фотографии, для которых найдена пара. Каждый вопрос показывает настоящую фотографию и соответствующую ей версию ИИ; расположение вариантов случайное. В одном тесте пары не повторяются. Максимум — 100 вопросов.
